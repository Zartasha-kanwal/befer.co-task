# Befer.co Frontend Task

This project was completed as part of an **internship assignment**.  
The goal was to implement a responsive frontend based on provided requirements, focusing on clean UI, layout structure, and modern frontend practices.

## 🔗 Live Demo
https://befer-co-task-e7kb.vercel.app

## 🛠 Tech Stack
- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **PostCSS**

## ✨ Features
- Responsive layout for different screen sizes
- Clean and structured UI components
- Flexbox-based layout implementation
- Reusable components and organized folder structure
- Optimized fonts using `next/font`

## 📁 Project Structure
- `app/` – Application routes and pages
- `src/` – Core components and logic
- `public/` – Static assets
- `tailwind.config.ts` – Tailwind configuration

## 🚀 Getting Started

To run the project locally:

```bash
npm install
npm run dev
Then open http://localhost:3000 in your browser.

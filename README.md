# Befer.co Frontend Task

This project was completed as part of an **internship assignment**.  
The goal was to implement a responsive frontend based on provided requirements, focusing on clean UI, layout structure, and modern frontend practices.

## 🔗 Live Demo
[https://befer-co-task-e7kb.vercel.app](https://befer-co-task-e7kb.vercel.app)

## 🛠 Tech Stack
- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **PostCSS**

## 🎨 Fonts
- Custom fonts used: **SF Pro Rounded** (multiple weights)  
- Stored in `/public/fonts/` and applied via Tailwind for consistent typography

## ✨ Features
- Responsive layout for all screen sizes  
- Flexbox-based layout implementation  
- Reusable components for modular design  
- Clean UI following provided specifications

## 📁 Project Structure
public/fonts/ # Custom SF Pro Rounded fonts
src/
Components/ # Reusable UI components
app/ # Pages and routes
assets/ # Images, SVGs, GIFs
